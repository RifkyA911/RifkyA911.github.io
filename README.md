## 🌐 Overview

This repository hosts the official web hub and open-source directory for **Rifky Akhmad F. ([@RifkyA911](https://github.com/RifkyA911))**, served live on **[https://rifkya911.github.io](https://rifkya911.github.io)** via GitHub Pages.

It acts as a centralized index for 45+ public software projects, libraries, and system architectures across **Rust**, **TypeScript**, **Go**, **PHP**, and **AI platforms**.

---

## ⚡ Architecture & Key Highlights

* 🏎️ **Zero Bundle Overhead:** Engineered with pure semantic HTML5 and scoped modern CSS. Zero heavy client frameworks, delivering near-instant sub-second First Contentful Paint (FCP) and a perfect 100/100 Lighthouse performance profile.
* 🔍 **Comprehensive Search Engine Optimization (SEO):**
  * **Schema.org Structured Data (JSON-LD):** Fully compliant with Google Rich Results for `ProfilePage`, embedding `Person` metadata and individual `SoftwareSourceCode` items for all 45 projects.
  * **Sitemap & Robots:** Automated [`sitemap.xml`](https://rifkya911.github.io/sitemap.xml) and [`robots.txt`](https://rifkya911.github.io/robots.txt) allowing search engines (Googlebot, Bingbot) to crawl and index outbound repository links.
  * **Verified Search Presence:** Integrated Google Search Console property verification.
* 📱 **Tokyo Night Glassmorphic Design:** Fully responsive layout with modern dark-mode aesthetic, adaptive CSS grid, and interactive card hover states.
* 📂 **Taxonomy & Categorization:**
  * **AI & Intelligent Systems:** Autonomous sentries, multi-agent orchestrators, LLM guardrails, Live2D avatar trackers.
  * **Systems & Backend Architecture:** High-concurrency engines, async APIs in Rust (`Axum`, `Tokio`), Go microservices, and Bun runtimes.
  * **Modern Web & Full-Stack:** Production templates, full-stack Next.js 16 / SvelteKit 5 / Nuxt 4 platforms.
  * **Tools & Utilities:** Open-source developer utilities, automation pipelines, and CLI tooling.

## 🚀 Local Development

Since this site is 100% dependency-free, you can serve it with any local static server:

```bash
# Using Python
python -m http.server 3000

# Using Bun
bunx serve .

# Using Node / npx
npx serve .
```

Open `http://localhost:3000` in your browser.
